How to Download or Print

  1. Click any "Preview PDF" button to open the report in a new tab
  2. The PDF will be displayed in your browser's built-in viewer
  3. Use the browser's download button (⬇) or print button (🖨) in the PDF toolbar
  4. You can also right-click and select "Save as..." or press Ctrl+P to print

API Endpoints

GET /reports/api/resident-statistics/
GET /reports/api/clearance-applications/
GET /reports/api/revenue/
GET /reports/api/resident-list/

All endpoints support query parameters: date_from, date_to, and optional filters. Add download=1 to force download instead of preview.
